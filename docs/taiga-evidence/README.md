# Taiga evidence

Screenshots of the backlog and sprint boards over time, showing weekly
progress (not a single retroactive snapshot). Include:

- Backlog view with user stories and their current status
- Each sprint's taskboard at a few points across its duration
- Burndown chart(s) if Taiga is tracking points

Name files with the date they were taken, e.g. `backlog-2026-10-07.png`,
so the weekly progression is obvious at a glance.
